  • CTF challenges
  • Security research


┌─────────────────────────────────────────────────────────────────────┐
│  HOW TO START (3 STEPS)                                             │
└─────────────────────────────────────────────────────────────────────┘

1. Find the file named "index.html" in this folder

2. Double-click it (opens in your web browser)

3. Click any purple button → Text appears → Copy it → Paste in ChatGPT

That's it! You're done! ✅
